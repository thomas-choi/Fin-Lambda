# finDeepCore -- layer shared by EVERY fin-deep-data function (python3.13).
#
# Separate from the fin-cron-data layers on purpose. finCron pins
# pandas==1.5.3 / SQLAlchemy==1.4.46 / numpy==1.26.4 (python3.10) and
# finPort313 bundles the web-scrape and yfinance extras in one 164 MB tree;
# neither is touched by this service. The split into three small layers
# (core / yf / web) keeps every layer well under the 80 MB ceiling and lets a
# function mount only what it imports.
#
# Build:  make finDeepCore.zip     (cross-builds cp313/manylinux2014_x86_64)
#
# boto3/botocore are deliberately absent: the Lambda python3.13 runtime ships
# them. Install them in the dev venv only (requirements-dev.txt at repo root).
